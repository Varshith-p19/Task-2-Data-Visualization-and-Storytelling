# Task-2-Data-Visualization-and-Storytelling


Project Overview

This project demonstrates how data visualization supports business storytelling, trend identification, and insight-driven decision-making.
Using Tableau, multiple visualizations and an interactive dashboard were created to analyze sales performance using a sample dataset of 100 rows.

**Objectives**

1.Choose the correct chart types based on the data
2.Build clean and meaningful visualizations
3.Create an interactive dashboard for insights
4.Tell a clear business story using visuals
5.Present findings in a PDF/portfolio-ready format

**Dataset Description**

The dataset includes the following fields:

Month
Region
Product
Sales
Profit
Profit Margin

Size: 100 Rows
Format: CSV / Excel

**Visualizations Created**

✔ 1. Sales Trend by Month

1.Horizontal stacked bar chart
2.Displays monthly sales split by region
3.Highlights seasonal trends and region-wise contribution

✔ 2. Sales by Region

1.Horizontal bar chart
2.Used for category comparison
3.Shows total revenue by region

✔ 3. Profit & Profit Margin Analysis (optional based on dashboard)

1.Dual-axis charts / bar charts
2.elps understand profitability and business performance
